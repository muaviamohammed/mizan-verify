# mizan-verify has moved

**This repository is archived.** Offline verification (published keys, ledger proofs, verifier binaries and checksums) now lives in the MIZAN monorepo:

**→ [github.com/muaviamohammed/mizan/tree/main/verify](https://github.com/muaviamohammed/mizan/tree/main/verify)**

- Verifier binaries + SHA-256 sums: <https://mizan.market/verify/>
- The standard (VTR-1, CC BY 4.0): <https://mizan.market/standard/> · specifications: [`specs/`](https://github.com/muaviamohammed/mizan/tree/main/specs)
- The releases on this repository (including the frozen VTR-1 v1.0 text) stay available.

MIZAN is the open standard for proof before payment. *x402 lets machines pay. MIZAN proves they earned it.*
